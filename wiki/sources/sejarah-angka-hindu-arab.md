# Sejarah Angka Hindu-Arab

_History of the numeral system (0-9) we use today — from India through the Islamic world to Europe._

## Timeline

### India (Origins)
- **3rd century BCE**: Brahmi numerals appear — ancestors of modern digits, but no place-value system
- **5th century CE**: Aryabhata uses "kha" (emptiness) as a placeholder in decimal system
- **628 CE**: **Brahmagupta** writes _Brahmasphutasiddhanta_ — first formal rules for zero as a number (n+0=n, n-0=n)
- **3rd-4th century CE**: Bakhshali manuscript uses dot symbol (evolved into circle for zero)

### Islamic World (Transmission & Refinement)
- **773 CE**: Indian astronomical text _Siddhanta_ brought to Baghdad, translated as _Zij al-Sindhind_
- **825 CE**: **Al-Khwarizmi** writes _al-Jam' wa-l-tafriq bi-hisab al-Hind_ — systematically maps Indian numerals and zero ("sifr") to Arabic mathematics
- The name "Al-Khwarizmi" → **Algorithm**

### Europe (Adoption)
- **~967 CE**: Gerbert of Aurillac (later Pope Silvester II) learns the system from Muslim scholars in Spain
- **1202 CE**: **Leonardo Fibonacci** publishes _Liber Abaci_ after studying in North Africa — convinces European merchants to switch from Roman numerals

## System Comparison

| Feature | Hisab Jummal (Semitic) | Hindu-Arabic (Modern) |
|---------|----------------------|----------------------|
| Symbols | Letters (Alif, Ba, Jim...) | Digits (0, 1, 2...9) |
| Zero | None (additive system) | Essential (placeholder) |
| Logic | One symbol = fixed value | Value depends on position |

## Key Figures

- **Brahmagupta** — formalized zero
- **Aryabhata** — placeholder concept
- **Al-Khwarizmi** — bridged Indian and Islamic mathematics; "algorithm" named after him
- **Fibonacci** — brought the system to Europe
