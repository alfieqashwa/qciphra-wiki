# Abjad Numeral System

_Summary of the Hisab Jummal / Abjad numeral system — an ancient alphabetic numeral system._

## What It Is

Hisab Jummal (Abjad) is an ancient alphabetic numeral system that assigns numeric values to Arabic letters. Before Hindu-Arabic digits (0-9) were adopted, civilizations used letters for counting.

## Key Facts

- **Origin**: Semitic root system, shared with Jewish Gematria (Hebrew alphabet has nearly identical order)
- **Order**: Abjad order is `Alif-Ba-Jim-Dal` (not the modern Hijaiyah order)
- **Three tiers**: Units (1-9), Tens (10-90), Hundreds (100-900), with Ghayn = 1000
- **Non-positional**: Values are additive, not positional (no concept of zero)
- **Historical use**: Commerce, poetry riddles, chronograms, Quranic analysis

## Historical Timeline

| Era | Development |
|-----|-------------|
| Pre-7th century | Abjad system used across Semitic civilizations |
| 680-700 CE | Nasr bin 'Asim & Yahya bin Ya'mur introduce Hijaiyah order (by shape similarity) and dotting system (Nuktah) |
| 7th century | Brahmagupta formalizes zero in India |
| 9th century | Al-Khwarizmi adapts Hindu numerals → "al-sifr" → zero/cipher |
| 1202 CE | Fibonacci's Liber Abaci spreads Hindu-Arabic numerals to Europe |

## Quranic Connection

- Huruf Muqatta'ah (e.g., _Alif Lam Mim_) — some scholars analyze these through Abjad values
- Bismillah value = 786 (sum of all letter values)
- Used in traditional healing, metaphysics, and chronograms
