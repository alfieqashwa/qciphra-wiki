# Alfie Qashwa

_Researcher and developer behind the qciphra project — computational analysis of Quranic numerical patterns._

## Projects

- **hisab-jummal-quran.vercel.app**: Hisab Jummal calculator and documentation
- **hisab-jummal-quran.vercel.app/checksum**: Checksum analysis tool
- **hisab-jummal-quran.vercel.app/keyboard**: Interactive Abjad keyboard
- **qciphra.netlify.app/checksum**: Odd-even parity analysis tool
- **qciphra**: This wiki — a compounding knowledge base for the research

## Research Focus

- Computational analysis of Quranic structure (primes, parity, checksums)
- Hisab Jummal (Abjad numeral system) implementation
- Number 19 patterns in the Quran
- Building open-source tools for independent verification
