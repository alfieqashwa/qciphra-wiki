# Ali Adams

**Ali Adams** (`علي عبد الرزاق عبد الكريم القره غولي`) adalah peneliti independen dan penemu sistem **Primalogy** — sistem numerologi yang menetapkan nilai bilangan prima berurutan kepada huruf-huruf Arab.

## Kontribusi Utama

1. **Primalogy System** — Pemetaan 29 huruf Arab ke bilangan prima berurutan (ا=2, ب=3, ... ي=107)
2. **Additive Prime Validation** — Mekanisme validasi: hasil prima + jumlah digit prima
3. **Golden Ratio in Quran** — Penemuan rasio emas (φ ≈ 1.618) dalam struktur C+V Quran
4. **Bi-symmetrical Book** — Analisis bi-simetris: 57 genap + 57 ganjil = 114 surah
5. **Iron Chapter Stability** — Surah #57 (Besi) sebagai surah paling stabil berdasarkan C×V product
6. **QuranCode** — Proyek open source C# untuk analisis numerik Quran (qurancode.com)
7. **Klasifikasi bilangan** — Terminologi sistematis: {U}, {P}, {AP}, {XP}, {C}, {AC}, {XC}, {AB}, {PF}, {DF}, {AM}, {Co}

## Quran = Key + Message

Kontribusi konseptual terbesar Ali Adams:

```
Quran = Key        + Message
114 chapters = 1   + 113     → 113 = AP
6236 verses  = 7   + 6229    → 7 = AP, 6229 = AP
```

Quran bernama "Al-Quran" karena **readable meskipun terenkripsi** — sebuah readable ciphertext. Surah adalah **unit enkripsi minimum** (bukti: Allah tidak pernah menghasilkan di bawah satu surah).
