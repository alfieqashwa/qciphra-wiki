# Brahmagupta

_Indian mathematician and astronomer (598–668 CE), first to formalize zero as a number._

## Key Contribution

In his 628 CE work _Brahmasphutasiddhanta_, Brahmagupta was the **first person to give operational rules for zero**:
- n + 0 = n
- n - 0 = n
- n × 0 = 0

Before him, zero was merely a placeholder (empty space), not a number with its own arithmetic properties.

## Context

- Built on Aryabhata's earlier "kha" (emptiness) concept
- His work was later translated and adapted by **Al-Khwarizmi**
- The Bakhshali manuscript (3rd-4th century CE) shows zero symbols predating Brahmagupta
