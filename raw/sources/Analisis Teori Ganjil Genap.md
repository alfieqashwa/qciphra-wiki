Al-Qur'an terdiri dari 114 surah dengan masing-masing jumlah ayatnya.
Jika urutan 1 hingga 114 di jumlahkan, totalnya adalah **<font color="#ffc000">6,555</font>**

Jika masing-masing jumlah ayatnya di jumlahkan, totalnya adalah **<font color="#92d050">6,236</font>**

Kini masing-masing urutan dijumlahkan dengan masing-masing jumlah surah (e.g 1 + 7 = 8, karena Al-fatihah di urutan 1 dengan jumlah ayat 7, dan juga 2 + 286 = 288, karena Al-Baqarah di urutan kedua dengan jumlah ayat 286).

Dari kesuluruhan hasil masing-masing surah dari kombinasi penjumlahan antara urutan + jumlah ayat, di dapatkan bahwa masing-masing terdiri dari **<font color="#ffc000">57 angka ganjil</font>** dan **<font color="#92d050">57 angka genap</font>**.

Jika di total, maka total keseluruhan angka ganjil adalah <font color="#ffc000">6555</font>, dan total keseluruhan angka genap adalah <font color="#92d050">6236</font>

### Calc Parity Surahs

| totalNumber | totalNumberOfAyahs | TotalOdd | TotalEven | OddLen | EvenLen | TotalLen |
| ----------- | ------------------ | -------- | --------- | ------ | ------- | -------- |
| 6555        | 6236               | 6555     | 6236      | 57     | 57      | 114      |


### Code

```ts
const URL = `https://api.alquran.cloud/v1/surah`;

interface ApiResponse {
  code: number;
  status: string;
  data: SurahData[];
}

interface SurahData {
  number: number;
  name: string;
  englishName: string;
  englishNameTranslation: number;
  numberOfAyahs: number;
  revelationType: string;
}

async function fetchSurah() {
  try {
    const response = await fetch(URL);
    if (!response.ok) throw new Error(`HTTP error: ${response.status}`);

    const { status, data } = (await response.json()) as ApiResponse;
    if (status !== "OK") throw new Error("Response status NOT OK!");

    return data;
  } catch (err) {
    throw err instanceof Error ? err : new Error(String(err));
  }
}

const surahData = await fetchSurah();

const paritySurahs = surahData.map((s) => {
  const sum = s.number + s.numberOfAyahs;
  const isEven = sum % 2 === 0;
  return {
    number: s.number,
    name: s.englishName,
    numberOfAyahs: s.numberOfAyahs,
    odd: isEven ? "" : sum,
    even: isEven ? sum : "",
  };
});

console.table(paritySurahs);

const calcParitySurah = paritySurahs.reduce(
  (acc, s) => {
    acc.totalSeq += s.number;
    acc.totalNumberOfAyahs += s.numberOfAyahs;
    acc.totalOdd += Number(s.odd);
    acc.totalEven += Number(s.even);

    s.odd !== "" ? acc.oddLen++ : acc.evenLen++;
    acc.totalLen++;

    return acc;
  },
  {
    totalSeq: 0,
    totalNumberOfAyahs: 0,
    totalOdd: 0,
    totalEven: 0,
    oddLen: 0,
    evenLen: 0,
    totalLen: 0,
  },
);

console.table({ calcParitySurah });
```
